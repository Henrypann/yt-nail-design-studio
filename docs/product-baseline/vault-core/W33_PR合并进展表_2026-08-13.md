## 一、状态字典

| 状态 | 含义 |
|---|---|
| `MERGED(main)` | 已进入本地 main；不代表 push、部署或 production-ready |
| `READY(branch)` | 独立分支已提交并验收，等待合入裁决 |
| `SELECTED` | 用户已选入当前执行方向；仍需按直接依赖和决策门建立分支 |
| `PLANNED` | 合同/范围存在，尚未开发 |
| `NEEDS_DECISION` | 有多个合理方向，需要先选产品目标 |
| `DEFERRED` | 依赖或证据不足，明确后置 |
| `RESEARCH` | 只允许研究/Spike，不进入产品或制造承诺 |

证据等级继续分开使用：`integrated / prototype / simulated / architecture-golden / physically-validated / production-ready`。
