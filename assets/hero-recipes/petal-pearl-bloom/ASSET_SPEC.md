# Petal Pearl Bloom · Look Asset Spec

基于单甲母题扩展的十指成套 Look。高保真图片用于 Community/Wizard 沟通；EditorDocV7 中的背景、平面、表面效果、立体装饰和封层才是可编辑结构，但仍仅属于模拟预览证据。

## 十指节奏

| 指位 | 结构 |
|---|---|
| L1 / R3 | 淡紫珍珠 + 银色圆珠簇 + 酒红微珠 |
| L2 / R4 | 透明水晶花 + 淡紫珍珠 + 酒红微珠 |
| L3 / R5 | 花瓣线稿 + 银色圆珠簇 |
| L4 / R1 | 花瓣局部晕染 + 酒红微珠 |
| L5 / R2 | 留白亮面 + 单颗淡紫珍珠 |

十指共用透明裸粉背景和透明亮面封层。水晶花与珠饰为 `attachment_3d` 模拟 GLB；花瓣线稿为 `image_2d` vector；局部着色为 `surface_effect.ink_bloom`。

## 证据边界

- `SIMULATED`：图片、SVG 2.5D、GLB 预览。
- 未验证：真实厚度、粘接、材料、UV 固化、侧壁安全区、佩戴与制造。
