# NextGen Beauty 全域功能需求池 Final｜2026-09-04

> 本地正式需求基线已提升至 2026-09-04：130 条、17 字段、231 个文字节点。所有条目仍为 `planned` 需求，不代表实现、物理验证或生产就绪。2026-09-02 的 127 条快照完整保留为历史来源。

## 结论与边界

- User 是唯一业务主体；设备一机一 owner，解绑留痕后才可换绑。
- 全部注册 User 均可建 Customer、进入 Studio、进行设计；设备 owner 仅额外获得设备管理和制造能力。
- Customer 跨 User 只允许授权与接受后的受控单一所有权转移；在制生产未结束时阻断；历史生产与审计不改写。
- 社区或模板进入 Studio 一律生成独立草稿；MVP 仅 2D 编辑与只读 3D 预览。
- 照片/手动尺寸只能选款、设计和近似预览。只有合格精准采集版本可生产；制造还必须通过固定版本、Customer 确认、TP01、设备、标定、材料、资源和制造包门禁。
